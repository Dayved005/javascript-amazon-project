# 🛒 Amazon Clone

A responsive Amazon-inspired e-commerce website built from scratch using **HTML, CSS, and JavaScript**.

This project was created as a hands-on JavaScript development project to practice building a functional e-commerce experience, working with APIs, managing application state, handling user interactions, and using Git/GitHub for version control.

## 🚀 Live Demo

**[View the live website](YOUR-VERCEL-LINK-HERE)**

## 📸 Features

* 🛍️ Product listing and display
* 🔍 Product search functionality
* 🛒 Shopping cart
* ➕ Add products to cart
* 🔄 Buy Again functionality
* 🚚 Delivery options
* 💳 Checkout and order summary
* 📦 Order placement
* 📋 Orders page
* 🚚 Order tracking
* 📱 Responsive design for different screen sizes
* 💾 Cart and order data management
* 🌐 Backend API integration
* 🧪 JavaScript unit testing with Jasmine

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling and responsive design
* **JavaScript (ES6+)** — Functionality and application logic
* **Day.js** — Date and time formatting
* **Fetch API** — Communication with the backend
* **Git & GitHub** — Version control
* **Vercel** — Deployment
